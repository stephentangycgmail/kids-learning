# Grammar Practice Manual Test

## Desktop - Chrome Or Edge

- [ ] Open `frontend/grammar_practice.html` through a local static server.
- [ ] Confirm only topics with enough questions are offered for each mode.
- [ ] Start each mode and confirm every session contains 20 unique questions.
- [ ] Confirm Mixed Practice contains 10 questions of each type.
- [ ] Move with Previous, Next, and the question navigator.
- [ ] Change an answer, refresh, and confirm the unfinished practice is restored.
- [ ] Confirm no correctness colour or score appears before submission.
- [ ] Review submission with answered and unanswered question numbers.
- [ ] Submit with an unanswered question after the warning.
- [ ] Confirm the result is locked and shows score, dates, duration, and explanations.
- [ ] Confirm Wrong Answers and All Questions views work.
- [ ] Confirm Practice History shows In Progress, Submitted, and Abandoned records correctly.
- [ ] Confirm a submitted record opens only as a result.

## Mobile And Tablet

- [ ] Confirm mode cards, blank choices, tokens, and navigation have comfortable touch targets.
- [ ] Build and correct a rearrangement answer by tapping tokens.
- [ ] Confirm a selected source token stays visible but disabled.
- [ ] Confirm duplicate token text can be selected and removed independently.
- [ ] Use Clear Answer and confirm all source tokens return.
- [ ] Rotate the device and confirm content remains readable without horizontal scrolling.
- [ ] Refresh during practice and continue from the saved question and answers.
